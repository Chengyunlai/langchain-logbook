# Research Report Skill

只有在任务要求形成研究报告、比较多个来源或交付带引用结论时，才加载本技能。普通事实问答不需要加载。

## 引用核验流程

1. 先把问题拆成可以分别验证的子问题，不把用户假设直接当事实。
2. 优先使用官方文档、标准、论文和项目源码；记录来源 URL、发布日期与事件日期。
3. 对会随时间变化的结论至少检查两个来源，区分来源原文、你的概括和推断。
4. 每个关键结论就近放置引用；无法验证的内容显式标记为未知，不编造引用。
5. 输出前检查报告中的 Artifact 路径、引用和验收清单是否一致。

## 交付结构

- 结论摘要：先回答用户真正要做的决定。
- 证据与限制：逐项说明依据、适用边界和仍不确定的内容。
- 建议方案：说明权衡，不把一个工具或框架描述成唯一答案。
- 验收清单：给出可以运行或人工检查的完成条件。

长证据正文应写入线程 workspace，向 Lead Agent 返回有界摘要和 `ArtifactRef`，不要把整个研究过程复制进主会话。
