# 03 项目导向的 About 与 README

- Status: resolved
- Triage: ready-for-agent
- Type: task
- Blocked by: 02

## Why

仓库脱离 fork network 后，README 和文档站 About 仍以个人维护者与历史关系为主要叙述，不利于读者快速理解项目本身的定位、学习产物和工程原则。

## Work

- 将 README 的仓库说明改为项目导向的独立维护声明。
- 将文档站 About 重写为项目定位、学习产物、工程原则与入口。
- 将首页个人维护者卡片改为项目简介。

## Acceptance

- README 不再以个人维护者或 fork 历史为主要说明。
- About 页面能回答项目是什么、解决什么问题、交付什么以及如何开始。
- 首页简介与 README、About 的项目定位一致。
- 文档站类型检查、构建和链接契约通过。

## Answer

README、About 页面和首页简介已统一为项目导向文案，不再以个人身份或 fork 历史作为主要叙述。
