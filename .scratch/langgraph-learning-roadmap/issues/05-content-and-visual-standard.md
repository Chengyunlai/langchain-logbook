# 建立详细教学内容与视觉表达标准

Status: resolved
Triage: ready-for-agent
Type: task
Blocked by: 04

## Why

用户明确要求不简化内容、提供必要中文解释和优化流程图。统一标准能避免有的章节只有比喻、有的章节只有代码，也能控制 imagegen 的使用边界。

## Work

- 定义章节闭环模板和代码解释粒度。
- 定义概念图、时序图、状态图、数据边界图、源码导航图的使用场景。
- 规定 Mermaid 可访问性、节点命名、颜色依赖和文本替代要求。
- 规定 imagegen 仅用于 Mermaid 无法有效表达的视觉隐喻或空间关系，并保存生成提示词与说明。
- 建立“错误示例 → 失败现象 → 根因 → 修复”的讲解模板。

## Acceptance

- 形成可被全部章节复用的中文写作和图示规范。
- 至少提供一套章节模板和五类图示模板。
- 图示在 Markdown、Notebook 和 Astro 文档站中均可阅读。
- 不以删除原理或工程细节换取篇幅缩短。

## Answer

已形成[LangGraph Agent 工程课程中文写作与视觉表达标准](../artifacts/05-content-and-visual-standard.md)。

关键结论：

- 建立“业务动机 → 概念定义 → 相邻边界 → 运行机制 → 工程权衡 → 证据与迁移”六层解释模型，以结构降低认知负荷，不通过删减工程细节缩短内容。
- 提供完整可复用的中文章节模板，覆盖问题建模、概念边界、最小实验、Mini DeerFlow 工程实验、失败实验、练习、自动验收和 DeerFlow 映射。
- 规定关键业务代码以 Python package 为事实源，Markdown 负责解释，Notebook 负责交互实验；代码片段和 Mermaid 使用稳定 marker，避免三端手工复制漂移。
- 建立五段式失败实验模板和配置、契约、状态、控制流、副作用、并发、质量、运行时八类错误覆盖表。
- 将 teach 方法落实为单点修改、边界判断、项目扩展、延迟回忆四类练习，以及分层提示、即时测试反馈、间隔与交错复习；遵循用户要求继续使用本地 Markdown，而不另建 HTML 课程体系。
- 提供概念层级、调用时序、状态机、数据/信任边界、源码导航、模式决策树、并行汇总七类 Mermaid 模板，并规定文本替代、亮暗主题、移动端和无颜色依赖要求。
- 形成 00–16 章必要图示清单。精确关系图全部优先 Mermaid；Imagegen 只用于非精确空间隐喻，当前没有必须生成的位图。
- 规定 Mermaid 单一源经 marker 生成 Notebook SVG，Astro 继续使用 `astro-mermaid`，CI 检查 source hash 和跨端一致性。
- 提供 24 分章节评审量规与完整发布自检清单。

该任务完成后，课程视觉资产范围已明确；后续内容重构任务仍需等待“建立版本、依赖与自动验证基线”。
