# 初学者解释层第二轮改造地图

## 目的地

在不删除现有实验、不改变核心 API 行为和已有 URL 的前提下，落实真实读者提出的第二轮反馈：先建立单次模型调用、固定执行管道（Chain）、自主选择动作的智能体（Agent）与显式管理状态和控制流的 LangGraph 认知坐标。Chain 的步骤由程序预先规定，Agent 会依据运行结果选择下一步，LangGraph 则负责把 Agent 或业务流程中的分支、循环、暂停和恢复显式化。

## 执行原则

- 保留现有实验、可运行练习本（Notebook）输出、Mini DeerFlow 工程深度和已有 URL。
- 优先调整信息出现顺序，不通过删除工程证据降低难度。
- Markdown 继续作为 Notebook 和文档站的事实源；Notebook 负责离线实验，不取代网页中的真实开发写法，所有入口同步验证。
