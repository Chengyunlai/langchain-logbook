- 用户完成一次 Web 样章阅读并指出仍然跳跃、冗余或不透明的位置。
- 反馈被整理为可执行修改，不由 Agent 代替用户作答。
- 把反馈整理成第 05、06 章和其余章节共同遵守的粒度修正，不再把“是否改全书”作为待决问题。
